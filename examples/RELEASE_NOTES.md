Three complete Flutter examples using the public DummyJSON API:

- Provider / ChangeNotifier
- Riverpod / Notifier
- BLoC / Cubit

Install one APK to test guest browsing, search, product details, sign in/out,
account-scoped cart and simulated checkout. The public demo credentials are
shown in the sign-in dialog. No internal server or secret key is required.

These are release-mode APKs signed with Flutter's test key, for evaluation.
Checkout is simulated: no charge or real order occurs. Do not enter personal
credentials or payment details into the public demo.
